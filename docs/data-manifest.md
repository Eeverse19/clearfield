# Data manifest

Every file below is public. Nothing under `data/` is committed to git; `scripts/download_data.py` (via the `.sh`/`.ps1` wrappers) reproduces the pinned files, and Barthelme MD5s are checked on download. THOR (section 4) is the one manual exception. Checksums marked ✓ were verified against the source-published value (Oct 22, 2026); GADM publishes no checksum, so its MD5s below are locally computed (Oct 26, 2026), not source-verified.

## 4. Strike / conflict records

- **THOR, Vietnam War** — data.world/datamil/vietnam-war-thor-data (free data.world account required; **manual download only — not scriptable**, `download_data.py` prints these steps and never fetches it). Downloaded file: `THOR_Vietnam.zip` (457,332,289 B, local md5 `3b39a4921f7c0912fbe961184911167e`). The zip uses **Deflate64 (method 9): Python `zipfile` and Windows `tar` cannot decompress it — extract with 7-Zip**: `& 'C:\Program Files\7-Zip\7z.exe' e THOR_Vietnam.zip -odata\thor`. Single member: `data/thor/THOR_Vietnam_7_31_2013.csv` (2,627,971,171 B; local md5 `939f28d770d9b3b9acd37553eab0fb85` — data.world publishes none). 85 columns (BOM on first header name — open as `utf-8-sig`); we use `TgtCountry` (`LAOS`/`CAMBODIA`/`SOUTH VIETNAM`/`NORTH VIETNAM`/`THAILAND`), `TgtLatDD_DDD_WGS84`/`TgtLonDDD_DDD_WGS84` (literal `NULL` = no coords), `SourceRecord`, `MSNDate`. Rows total 4,670,422 (1965-06-01..1975-06-30); missions WITH coordinates (counted by us, superseding the data.world page's lower claims 1,041,519 / 1,620,422 / 581,897 / 144,944 / 2,427): Laos 1,087,019; South Vietnam 1,658,608; North Vietnam 607,482; Cambodia 147,097; Thailand 2,574. Records targets, not impacts. Feeds `zones.strike_density` (missions per km2) via `scripts/seed_thor.py`. **Barthelme corrections:** Barthelme et al. 2024 (§2.5 + supplement Text S2) show the coordinates are in the Indian 1960 datum, not WGS84 (EPSG:4131→4326, ~500 m shift), B-52 missions are double-counted from 1971 across SACCOACT/SEADAB, and weapon types need filtering/imputation to crater-forming bombs. The corrected seed contract is pinned in `docs/thor/thor_final_spec.md` §9 (2026-10-28): forced EPSG:1542 datum transform (§9.1) and SACCOACT dedup from 1971-04-01 (§9.2) are pinned for `seed_thor.py`; the weapon-type filter is **not** applied — U17 mission counting stands (D1–D4 confirmed by owner 2026-10-28 as pinned defaults; decision record: `docs/thor/thor_final_spec.md` §9.6). **Seeded 2026-10-28: assigned 3,401,836 (cambodia 191,184 / laos 1,090,845 / vietnam 2,119,807), outside 108,385, corrected mismatch 144,468; strike_density non-NULL 106/106.** (Baseline history, clearly labelled: the earlier `--dry-run` reproduced the baseline-A scan expectation rows_read 4,670,422 / invalid_coords 1,130,146 / baseline_assigned 3,419,286 exactly before the corrected real run; baseline-A figures are not seeded facts.)
- **UCDP GED** — ucdp.uu.se/downloads, free, no registration, CC BY 4.0 (modern conflicts)
- **ACLED** — acleddata.com, free myACLED account (modern conflicts, near-real-time)

## 5. Imagery, boundaries, geography

- **KH-9/CORONA raw scans** — USGS EarthExplorer, Declassified Data > Declass 3, free USGS account
- **Georeferenced KH-9** — Edinburgh DataShare: Quang Tri doi 10.7488/ds/7682, tri-border doi 10.7488/ds/7683. Downloaded 2026-10-28 (`scripts/download_kh9.py`): all 8 m/px frames (Quang Tri 4, tri-border 6; 3.5 GB total, EPSG:32648, locally computed MD5s in `data/kh9/summary.json` — DataShare publishes no checksums). The 1 m/px frames (~120 GB) are deliberately not bulk-downloaded; read windows from the DataShare bitstreams with rasterio when detector validation needs them. Derived product (2026-10-28): `data/kh9/bomb_coordinates.csv.gz` + `.geojson` — all 541,397 seeded craters with lon/lat, UTM, KH-9 frame and 8 m/px (plus derived 1 m/px) pixel references; 99.996% on valid frame pixels; see `docs/kh9-coordinates.md`.
- **Current imagery** — Sentinel-2, Planet NICFI tropics mosaics
- **Sentinel-2 scene catalog (not imagery)** — `scripts/sentinel2_catalog.py` (Earth Search STAC v1, the endpoint behind registry.opendata.aws/sentinel-2; GADM 4.1 admin-0 `intersects`, never bbox). Completed 2026-10-28: 630,318 scenes, every count identical to the API `numberMatched`, 0 duplicate ids. `data/sentinel2/catalog/{laos,cambodia,ukraine}_sentinel-2-{l1c,l2a}.csv.gz` (id, datetime, MGRS tile, platform, cloud cover, bbox, B02/B03/B04/B08 hrefs, STAC item URL) + `{country}_mgrs_tiles.geojson` + `summary.json/.md`. Laos 55,883 L1C / 64,850 L2A (54/50 tiles); Cambodia 44,061 / 50,881 (40/36); Ukraine 192,484 / 222,159 (106/102). L2A hrefs are public COGs; L1C hrefs are `s3://` in the Requester-Pays bucket. Ukraine is catalogued by geometry only; it has no `countries/` profile.
- **CBERS-4A WPM scene catalog (not imagery)** — `scripts/cbers_catalog.py` (Brazil Data Cube STAC, collection CB4A-WPM-L2-DN-1; BAND0 2 m pan + BAND1-4 8 m MS, CC BY 4.0). Catalogued 2026-10-30: Laos 5 scenes (all 2025-08-28; 2 footprints overlap Xiangkhoang `LAO.18_1`), Cambodia 4 (none over Tbong Khmum), Ukraine 17 (2021-04-15..2026-10-22) -> `data/cbers/{country}_cbers4a_wpm.csv` + `summary.json/.md`. L2 system-corrected, not orthorectified; sparse/downlink-driven — a supplement, not coverage.
- **WorldStrat HR chips (auxiliary, benchmark only)** — Zenodo 6810792 (NeurIPS 2022): ~3,928 Airbus SPOT chips at 1.5 m/px (~2.5 km² each, single date 2013–2021) paired with Sentinel-2 revisits. `scripts/download_worldstrat.py` selects chips whose centre falls in the GADM admin-0 polygon: **Laos 4, Cambodia 11, Ukraine 62 (77 total)** -> `data/worldstrat/{country}/<chip>/` (`*_rgb.png`, `*_ps.tiff`, `*_pan.tiff`, `*_rgbn.tiff`) + `index.csv` (incl. the 16 matched `lowres_dates` per chip, not downloaded) + `summary.json`. Source archive `hr_dataset.tar.gz` (41,542,117,051 B, md5 `ca7167334006f3c17f9071f14c435335`) is downloaded resumably, MD5-verified, extracted, then deleted; `metadata.csv` (14,562,136 B, md5 `dfeb3348e79b719bf03c230d5d258839` ✓ source-published) is kept. HR license **CC BY-NC 4.0** (non-commercial only). Status 2026-10-28: **complete** — tar MD5-verified, 77/77 chips extracted (Laos 4, Cambodia 11, Ukraine 62), tar deleted; one Laos chip (`Landcover-1537543`, HR 2021-04-16) lies inside Xiangkhoang. Not zone evidence: 0.01–0.04% country coverage, and Ukraine chips predate 2022.

## 6. Labeled damage data (modern conflicts)

- **UNOSAT damage assessments** — unosat.org/products, mirrored on data.humdata.org. Per-city/per-event GIS data, classes: destroyed / severe / moderate / possible. No bulk file; collect per area of interest.

## Not available (by design)

Official hazard-area polygons (national IMSMA databases: Laos NRA, Cambodia CMAA, etc.) are behind operator accreditation everywhere. ClearField never depends on them; published province-level statistics are used instead.
