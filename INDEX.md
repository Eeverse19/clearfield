## Start here by task

| I want to… | Go to |
|---|---|
| Run the app / see the map | `Start-ClearField.bat`, or `uv run uvicorn backend.app.main:app --port 8000` → http://127.0.0.1:8000/ |
| Watch live pipeline progress | `py -3.12 scripts/dashboard.py` → http://127.0.0.1:8765/ |
| Know what's done / blocked | `TASKS.md` (top addendum is current), then `README.md` status block |
| Reproduce all data from scratch | `docs/getting-started.md`, then `docs/data-manifest.md` (every dataset, checksum, script) |
| Understand the design rules | `docs/architecture.md` (one job per model, hard rules) |
| Use the KH-9 crater coordinates | `docs/kh9-coordinates.md`, data in `data/kh9/bomb_coordinates.*` |
| Know what the research concluded | `docs/bomb-finding-research.md` (methods, doctrine, modelling rules) |
| Add a country | `countries/README.md` + copy a profile in `countries/` |
| Seed / reseed the local DB | `scripts/seed_db.py`, then `scripts/seed_thor.py` (needs `data/thor/`), `pipelines/osm_exposure.py`, `pipelines/scoring.py` |
| Run tests | `uv run pytest` (set `UV_LINK_MODE=copy` on this OneDrive checkout) |

## Where things live

- `backend/` — FastAPI app (`backend/app/main.py`): `/`, `/zones`, `/finds`, `/buildings/{country}`, `/health`. Serves `frontend/index.html`.
- `frontend/` — single-file map GUI (satellite basemap, zone layers, buildings overlay, find recording).
- `pipelines/` — data pipelines that write zone columns: `scoring.py`, `osm_exposure.py`, `building_exposure.py`, `tiling.py`, `sam_segment.py`.
- `scripts/` — one-off data acquisition + utilities: `download_*.py`, `sentinel2_catalog.py`, `seed_*.py`, `kh9_match.py`, `dashboard.py`, `filemap.py`.
- `countries/` — country profiles (config, never code). `db/` — schemas (SQLite mirror + PostGIS target, identical column names).
- `data/` — gitignored datasets and outputs; layout in `data/README.md`. Nothing here is committed; every file is reproduced by a script in `scripts/` or `pipelines/`.
- `docs/` — architecture, getting-started, data-manifest, demo-script, kh9-coordinates, bomb-finding-research, `thor/` (THOR specs).
- `agent/`, `field/` — Spark agent (stub, needs META_API_KEY) and offline Glimmer triage (stub).
- `demo/` — cached demo responses (currently just a README; P1-5).
- `tests/` — pytest suite; handlers are called directly, no sockets.

Two dated records are kept for history, not current state:
`WORKFLOW_SYNTHESIS.md` (Oct 27 audit) and `SESSION_HANDOFF.md`
(paused-session handoff). Trust `TASKS.md` over both.
