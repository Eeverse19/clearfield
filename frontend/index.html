    How to read this map

    Color = one score ingredient at a time. Switch layers above. Darker grey means no data — that is not zero. A real zero gets the lightest color step.

    Official priority needs all three ingredients multiplied together: THOR strike density × crater evidence × exposure. Strike density is not seeded yet, so today's list is an evidence preview, never a clearance order.

    ◆ marks the demo province. Colored dots are field finds recorded in this browser (green = saved to the database, amber = queued offline).

    Shortcuts: / search · ←→↑↓ pan (map focused) · +/− zoom · Esc cancel find mode. Every zone is also reachable from the ranking list — the map needs no mouse.
